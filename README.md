# 🎃 Kitzch-Pop Halloween | Candy Catch Szn 🍬

> A high-energy, retro-arcade browser game celebrating Halloween with Y2K scrap-sticker aesthetics, celesta soundscapes, and fortune wish drops. Inspired by the [Kitzch-Pop Halloween](https://kitzchpophallowen.oneapp.dev/) universe.

🎮 **Play Live Online:** [https://thedenism.github.io/kitzch-pop-halloween/](https://thedenism.github.io/kitzch-pop-halloween/)

![Kitzch-Pop Halloween Banner](public/og-image.png)

## ✨ Game Features

- 🍭 **Delicious Candy Treats**:
  - Candy Corn (+10 pts)
  - Chocolate Bar (+25 pts)
  - Caramel Apple (+40 pts)
  - Mystery Candy (+50 pts & surprise bonus)
- ⚡ **Special Power-ups**:
  - 🌙 **Moon Magnet**: Sweeps candies straight toward your pumpkin basket
  - ⚡ **Sugar Rush (x2)**: Doubled points and high-speed reflexes
  - 🛡️ **Shield Ring**: Absorbs cursed orb attacks
  - 🪅 **Ghost Piñata**: Bursting festive candy bonanza
- 🔮 **Mythic Fortune Wishes**:
  - Crack open your Halloween mystery box after each run to reveal custom slang fortune drops (*Common*, *Rare*, *Mythic*).
- 📖 **Grimoire & Wardrobe**:
  - Unlock spooky achievements and switch between 5 custom pumpkin skins (*Classic Jack*, *Neon Cyberglow*, *Phantom Violet*, *Candy Witch*, and *Golden Ghoul*).
- ☁️ **Cloud Storage**:
  - Built-in 1-click upload to **Google Drive** and **GitHub**.

## 🚀 Quick Start (Local Development)

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/kitzch-pop-halloween.git
cd kitzch-pop-halloween
```

### 2. Install dependencies
```bash
npm install
# or
bun install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + custom typography (`Pirata One` & `Space Grotesk`)
- **Rendering**: High-performance HTML5 Canvas 2D engine (60 FPS particles, ambient bats, and physics)
- **Audio**: Web Audio API Sound Synthesizer + Celesta chord progression
- **Integrations**: Google Drive REST API, Firebase Auth, GitHub REST API
